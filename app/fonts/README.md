# Portfolio fonts

These Latin WOFF2 files are the same Google Fonts previously fetched during the portfolio build. They are bundled locally so the portfolio's typography and opening loader do not depend on Google Fonts being reachable.

Barlow Condensed uses weights 600, 700, and 800. Poppins uses 500, 600, and 700. Inter is variable; Newsreader includes regular and italic variable files. Their original SIL Open Font Licenses are included alongside the files.

Sources: https://github.com/google/fonts/tree/main/ofl/barlowcondensed, https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/newsreader, and https://github.com/google/fonts/tree/main/ofl/poppins.
